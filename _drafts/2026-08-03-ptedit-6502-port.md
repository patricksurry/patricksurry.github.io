  - Where the Python model turned out to be lying. It models the ordering
    discipline but not the address arithmetic — owner pieces hold Python
    strings and the runtime frees whatever falls out of scope. This section
    is the honest accounting of what that hid.
  - The ladder as a 64-slot ring buffer: 2^6 entries x 4-byte Locations =
    256 bytes exactly, with the three indices as byte offsets and index
    arithmetic modulo the size.
  - The scroll sub-case that the Python folds into "full redraw" — on real
    hardware a video-RAM block move plus a repaint of newly exposed rows.
